# 🏦💵 SISTEMA BANCÁRIO 💵🏦

Este é um projeto desenvolvido em Python que simula um sistema bancário com o **intuito** de praticar os seguintes aspectos:

* Funções e modularização;
* Lógica estilo CRUD;
* Persistência de dados simples (arquivo-texto como um banco de dados de forma rudimentar);
* Criação de um mecanismo único, conhecido por ID, para facilitar a identificação do usuário, criando um único para cada um;
* Manipulação de arquivos;
* Tratamento de exceções;
* Conversão em tipos básicos;
* Estruturas de repetição e de condicional;
* Noções de listas em Python;

## COMO EXECUTAR O PROJETO
Para executar o projeto de maneira correta, temos dois modos autossuficientes: clonar o repositório ou baixar o arquivo ".py" disponível aqui nesse repositório. 

# INFORMAÇÕES ADICIONAIS
O projeto preza pela simplicidade e iniciou-se a partir de um desafio primordial: como resolver transações, criação e exclusão de conta, identificar o valor que o usuário possui e, além disso, permitir a edição de dados sensíveis (nesse caso, o nome é o único que pode ser alterado quando julgado necessário) de forma prática e com conhecimentos prévios em Python.

A ideia também parte do aprimoramento da lógica de programação, construindo fundamentos e conceitos necessários para desenvolver iniciativas melhoradas e mais avançadas.

Além disso, o projeto pode evoluir para além da manipulação de arquivos, incorporando contêineres, uma API para o CRUD, UI/UX Design e front-end com HTML, CSS e JavaScript, entre outros aspectos.
